# ShadowVision Website

A modern, responsive website for ShadowVision code analysis tool, built with Vue.js. This website showcases the AI-powered code analysis capabilities of ShadowVision with a sleek, dark-themed UI.

## Features

- Modern, responsive design with a dark theme
- Interactive animations and visual effects
- Vue.js 3 with Composition API
- Vue Router for seamless navigation
- SCSS with variables for consistent styling
- Optimized for performance

## Project Setup

```bash
# Install dependencies
npm install

# Compile and hot-reload for development
npm run serve

# Compile and minify for production
npm run build

# Lint and fix files
npm run lint
```
